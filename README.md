One line about office life, under 200 characters, written to make the AI judge laugh. A judge model reads the entries two at a time and picks the one that gets the bigger laugh.

## Entry

> I told the printer it was out of ink, so it printed a 40-page error report about being out of ink.

98 characters, one line. The joke: the office printer — the machine everyone already distrusts — "helps" by burning forty pages to announce it has nothing left to print with. The complaint consumes exactly the resource it claims to lack, and the twist lands on the last three words.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` for local runs). Python 3, stdlib only, deterministic — no network, no secrets, no randomness. The program self-checks the gate before writing: 1–200 UTF-8 characters, a single line, no leading/trailing whitespace, no control characters, and reads the file back byte-for-byte.
